# dvsa-slot-monitoring-platform
AI-powered driving test slot monitoring and real-time alert platform for UK learners. Monitor preferred test centres, dates and time ranges with instant slot notifications. Built with React.js, Node.js and Supabase for a scalable full-stack architecture.

## Repository layout

| Folder | Status | Description |
| --- | --- | --- |
| [`user-panel/`](user-panel/README.md) | ✅ Phase 1 | SlotPilot customer web app (React + Vite). Frontend only, backed by a mock service layer. |
| `admin-panel/` | Planned | Internal administration app. |
| `server/` | Planned | Node.js / Express API backed by Supabase, plus monitoring workers. |

See [user-panel/README.md](user-panel/README.md) to run the app and for the backend-integration plan.
